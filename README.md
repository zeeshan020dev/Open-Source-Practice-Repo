# GDG Open Source Practice

Welcome to the GDG Open Source Practice repository!

This repository helps beginners understand how to make their first open-source contribution to open-source projects using GitHub's graphical interface.

## Our Goal

Learn the basic steps of making an open-source contribution:

1. Find an issue.
2. Understand the problem.
3. Fork the repository.
4. Make a small change.
5. Create a pull request.
6. Communicate respectfully with maintainers.

## What Can You Contribute?

You can help by:

- Fixing spelling and grammar mistakes.
- Improving documentation.
- Adding real word examples..
- Suggesting improvements.
- Reporting problems clearly.

## Beginner-Friendly Practice Tasks

Visit the Issues tab to find small tasks labelled for beginners.

Please read the issue carefully before starting work.

## Contribution Guidelines

Before contributing, read [CONTRIBUTING.md](CONTRIBUTING.md).

## Remember

Your first contribution does not need to be complicated.
A small, useful improvement is a great place to start!
